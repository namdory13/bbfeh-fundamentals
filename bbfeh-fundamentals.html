Mục tiêu học tập

Bài lab giúp sinh viên hiểu cách thức hoạt động của kỹ thuật Bipolar Backward-Forward Echo Hiding (BBFEH) trong giấu tin âm thanh. Sinh viên sẽ quan sát cấu trúc kernel BBFEH, nhúng chuỗi bit vào file âm thanh, tạo ảnh phổ để so sánh file gốc và file stego, sau đó tách lại thông điệp bằng phân tích Real Cepstrum.

Kỹ năng đạt được

  • Sử dụng ffprobe và sox để kiểm tra thông tin file âm thanh.
  • Hiểu vai trò của các tham số d0, d1, alpha và độ dài đoạn L.
  • Quan sát kernel BBFEH gồm 4 xung echo có tính đối xứng thời gian và lưỡng cực.
  • Thực hiện nhúng chuỗi bit vào audio để tạo file stego.wav.
  • So sánh phổ tín hiệu của file cover và stego bằng spectrogram.
  • Tách tin bằng cách so sánh đỉnh cepstrum tại hai vị trí trễ d0 và d1.

3. Kiến thức bổ trợ

Echo Hiding

Echo Hiding là kỹ thuật giấu tin bằng cách thêm một hoặc nhiều bản sao trễ của tín hiệu âm thanh gốc. Độ trễ echo rất nhỏ nên người nghe khó nhận ra, nhưng khi phân tích cepstrum, các vị trí delay có thể tạo ra đỉnh đặc trưng. Bit 0 và bit 1 được phân biệt bằng hai delay khác nhau.

Bipolar Backward-Forward Echo Hiding

BBFEH kết hợp hai ý tưởng: đối xứng thời gian của Backward-Forward Echo Hiding và lưỡng cực dương/âm của Bipolar Echo Hiding. Kernel BBFEH có bốn xung: hai xung tại ±d0 và hai xung tại ±d1. Các xung được chia biên độ theo alpha/4 để giữ tổng mức echo nhỏ, giúp tín hiệu stego khó bị nhận biết bằng tai.

Logic tách tin bằng Real Cepstrum

Khi tách tin, tín hiệu stego được chia thành từng đoạn có độ dài L. Với mỗi đoạn, detector tính Real Cepstrum và so sánh giá trị tại hai vị trí trễ: 

Nếu cepstrum[d0] > cepstrum[d1]  → bit 0
Nếu cepstrum[d1] > cepstrum[d0]  → bit 1
Tham số Ý nghĩa
d0 Delay dùng để biểu diễn bit 0 hoặc vị trí so sánh thứ nhất.
d1 Delay dùng để biểu diễn bit 1 hoặc vị trí so sánh thứ hai.
alpha Biên độ echo. Alpha càng lớn thì detector dễ phát hiện hơn nhưng âm thanh dễ bị biến đổi hơn.
L Độ dài mỗi đoạn nhúng một bit. L lớn thường giúp tách tin ổn định hơn nhưng làm giảm dung lượng.
Lưu ý: Trong lab này, sinh viên không cần tự lập trình thuật toán từ đầu. Các script embed.py và detector.py đã được cung cấp để tập trung vào việc quan sát quy trình giấu tin và tách tin.

4. Các nhiệm vụ của bài thực hành

Khởi động Lab:
Trước khi bắt đầu bài thực hành, sinh viên cần tải module lab, tải image Docker và khởi động môi trường Labtainers:

docker pull namdory13/bbfeh-fundamentals.analyst.student:latest
labtainer bbfeh-fundamentals -r

Sau khi khởi động lab, sinh viên làm việc trong terminal analyst. File âm thanh gốc nằm tại /home/ubuntu/audio/cover.wav. Thông điệp cần giấu nằm trong message.txt.

Quy trình chung:
Kiểm tra audio → quan sát kernel BBFEH → nhúng tin → so sánh cover/stego → tách tin bằng cepstrum → ghi nhận kết quả.
Chuẩn bị — Kiểm tra môi trường và file âm thanh

Kiểm tra các file được cung cấp trong thư mục làm việc:

ls
ls audio
cat message.txt

Kiểm tra thông tin file audio bằng ffprobe:

ffprobe audio/cover.wav

Thống kê tín hiệu audio bằng sox:

sox audio/cover.wav -n stat
Kết quả kỳ vọng: Sinh viên xác định được file cover.wav tồn tại, đọc được thông tin định dạng, tần số lấy mẫu và thống kê cơ bản của tín hiệu.
